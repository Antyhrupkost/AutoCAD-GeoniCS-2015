
BD_Fast_Draw_AVTO - скрипт, позволяет быстро создавать полилинию по геоточкам с авто привязкой, автоматически присваивая тип линии согласно коду, вдоль которого построена линия. Сортировка происходит по коду первой выбранной геоточки, продолжая привязываться только к близлежащим точкам с таким же кодом или кодом имеющим в составе себя первоначальный код. Либо программа не распознают код геоточки и будет магнитится к просто точкам без разделения. ПКМ отменяет один шаг, при каждом нажатии. 

dumpobj - это скрипт для вывода всей информации о геоточке, её тэгах и атрибутах. Эта информация позволяет создать работающий LISP или отредактировать существующий под особенности вашей версии программы. 

AutoRotateGP - скрипт автоматически вращающий высотные отметки вдоль линий, к которым они принадлежат.

off_even_label - отключает видимость всех чётных высотных отметок, оставляя точки видимыми. Скрывается только информация о высоте отметки. 

Создайте отдельную папку под файлы-скрипты. В папке создайте .txt документ и вставьте скрипт.
В Блокноте нажмите Файл -> Сохранить как. Сохраните с расширением .lsp. Выберите кодировку ANSI и сохраните файл _____.lsp. В AutoCAD введите команду (APPLOAD), выберите этот файл и нажмите «Загрузить». В командной строке должно появиться подтверждение успешной загрузки. Кодировка ANSI корректно переводит русские символы программе.
Раздел со списком стилей полностью настраиваемый, предполагает добавление и изменение. Для того чтобы стиль линии отобразился, в проекте должен быть шаблон с этими стилями, на него мы и ссылаемся в списке программы. 


hide_alt - “отключает” выбранную точку, заменяет инструмент “Показывать отметку НЕТ” в окне свойств. Выберите: Сервис, Адаптация, Изменение параметров программы. Внизу списка команд добавьте эти команды, если их нет:
С,             	*HIDEALTCYCLE
C,             	*HIDEALTCYCLE
Нажимаем Ctrl+S и закрываем окно, вводим команду “ПЕРЕИН” и пробел чтобы её выполнить. В окне ставим галочку напротив pgp✅ и ОК.
